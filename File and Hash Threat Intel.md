#  Writeup: File and Hash Threat Intel 🔍

## 🕵️‍♂️ Introduction
This walkthrough is an excellent exercise for practicing Cyber Threat Intelligence (CTI) skills, specifically in the investigation of malicious hashes and, above all, how to generate them.

During the investigation, I used the following tools and techniques:
* **Generate Hashes:** Powershell
* **Research on hashes**: Virustotal and MalwareBazaar

## 🚩 Walkthrough (Step-by-Step)

### Task 1: Introduction  
The purpose of this walkthrough is to analyze malicious files, generate file hashes to scan them on VirusTotal, observe the files' behavior in a sandbox, and, most importantly, map them to the MITRE ATT&CK framework.

### Task 2: Filenames and Paths
In this theoretical exercise, we first learn about the locations where malware is commonly found, such as:

**C:\ (System drive)**, which is a common location because it is used to ensure persistence.

**C:\Users\Public**, since this folder is accessible to all Windows users; some malware is often placed there because it allows the malware to persist and run automatically.

**C:\Users\Public\Public Downloads** Some malware is placed here to evade detection, since the downloads folder is a high-traffic directory, allowing the malware to go unnoticed.


They also explain the following common filename heuristic indicators:

**Double extensions**: An example is instructions.pdf.exe

**System binary impersonation**: An example is svchost.exe; it is important to know the legitimate locations of system files.

**High-entropy strings**: An example is jh8F21.exe. This suggests automated packing or polymorphic generation and is used to evade antivirus detection.

**Masquerading**: An example is backup-2300.exe. This involves using names that go unnoticed or seem routine, as some employees may be distracted when checking filenames.


Answer to the question: **One of the files in the “CTI Files” folder on the desktop displays one of the indicators mentioned. Can you identify the file and the indicator? (Answer: file, property).** It would be **payroll.pdf, Double extensions.** Because, even though the name contains .pdf, we know that the actual extension is .exe

### Task 3: File Hash Lookup
In this exercise, we will learn how to generate a hash of a file using PowerShell, as well as how to search for and analyze hashes on VirusTotal.

To answer the following question: “What is the SHA256 hash of the file bl0gger?”, we must use the command **certutil -hashfile bl0gger.exe SHA256**, which will give us the hash: 2672b6688d7b32a90f9153d2ff607d6801e6cbde61f509ed36d0450745998d58
